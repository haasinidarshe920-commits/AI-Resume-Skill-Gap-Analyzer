# AI Resume Skill Gap Analyzer

An AI-powered Streamlit application that analyzes resumes and identifies matching and missing skills.

## Technologies Used

- Python
- Streamlit
- PyPDF2
- NLP
- Machine Learning concepts

## Features

- Upload resume in PDF format
- Extract resume text
- Identify relevant AI/ML skills
- Calculate resume skill match score
- Display matched skills
- Display missing skills

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
